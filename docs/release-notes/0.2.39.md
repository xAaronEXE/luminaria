# Luminaria 0.2.39

A new look, a library that knows your PC, and leaner context for long tasks.

**New look.** Frosted glass panels float over slow aurora light, and the **Lumen** orb replaces the torus in everyday use. A small Lumen in the top bar always says what the assistant is doing ("Ready", "Working", or the current step). It turns amber when an action needs your approval. Pick the glow in Settings › Appearance: Aurora, Ember, Ocean, Forest, Mono or Off. Low-end PCs get solid panels automatically, and everything respects the Motion setting. The 3D scene remains in Task overview and voice mode, now behind the glass instead of over your text.

**Simpler layout.** The sidebar holds your tasks. Models, Skills, Memory, Automations, Tools, Integrations and Archive are one **Library** menu, each with a short description. The top bar shows whether Luminaria will **Ask me first** or run **Hands-free**. Settings use on/off switches, and access mode is two plain choices.

**Model ratings for your PC.** The library detects your graphics card and memory, for NVIDIA, AMD and Intel through the bundled runtime, and rates every model and quantization: Recommended, Runs well, Runs slowly, May be unstable or Too large. Each rating explains where the model would run, how much context fits, and how much memory it needs. "Best fit" marks the highest-quality quantization that earns the best rating. If detection is wrong, correct it under This PC. Ratings are estimates; results vary with drivers, settings and other open apps. A benchmark replaces the estimate with a measurement.

**Tuning without the guesswork.** For an installed model:
- **Use recommended settings** applies the estimate in one click.
- **Find best settings** measures a few settings around it.
- **Adjust** lets you set context, GPU layers, expert layers on the CPU and batch size by hand.

Mixture-of-experts models such as Qwen3 30B-A3B and gpt-oss 20B can keep attention on the GPU and run expert weights from system memory. That makes them practical on 12–16 GB cards.

**Abliterated models** have a distinct Unbound look: a broken-ring mark and a crimson-to-violet glow.

**Faster long tasks.**
- Older tool output in a request shrinks to its start and end, with a pointer to the full text, which stays saved.
- Files read again are sent only once.
- The plan no longer sits at the top of every request, so the model's prompt cache survives each step instead of reprocessing the whole conversation.
- Compaction reads trimmed tool output, so it finishes in fewer, faster passes.

**New branding.** A new app icon and social preview built around the Lumen orb.
