- Connect GitHub, Linear, Notion, Slack, Gmail, Google Drive and Google Calendar from Tools & integrations. Linear and Notion use browser sign-in. GitHub uses your own access token. Slack and Google need your own OAuth app. Credentials are encrypted for your Windows account. An integration shows as connected only when its tools actually loaded.
- Custom MCP connectors start as soon as you save them, and can be removed.
- The skills library is grouped by purpose. Each skill says whether it is ready or what it still needs, such as the GitHub integration or computer and command tools. Imported skills can be loaded from a .md file and removed.
- Attach PDF and Word (.docx) files, or a whole folder. Originals are kept in My files and the model reads their text.
- Chats in the trash can be deleted permanently, one at a time or all at once.
- Models have a quality check, kept separate from speed tests: 12 coding and reasoning questions with exact answers.
- The 3D core looks different while listening, thinking, speaking, interrupted and on error.
- Panels show a loading state and a Try again button if they fail to open. Form fields have higher-contrast borders.
