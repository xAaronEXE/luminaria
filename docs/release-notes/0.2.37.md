# Luminaria 0.2.37

Centers the desktop window on the monitor where the pointer is when the app opens, including after an update or sign-in restart. Placement uses the monitor's usable area so the taskbar is respected, and the window shrinks to fit smaller or scaled displays.

The window is positioned before it appears. Normal dragging and resizing remain available afterward.


The fresh-install sign-in fix from 0.2.36 remains included. Cloud-sync limitations and the unsigned installer status remain unchanged from 0.2.36.
