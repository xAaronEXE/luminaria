# Luminaria 0.2.36

Fixes a fresh installation opening the workspace without asking for sign-in. New installations now require Google, GitHub or Discord sign-in before the workspace opens. Existing saved sign-in preferences are preserved.

Startup also keeps the workspace locked if the sign-in check fails, with a retry screen instead of bypassing login.


Cloud-sync limitations from 0.2.35 remain: production second-PC/offline-conflict and final native visual acceptance are pending; phone access is not implemented; cloud sync is not end-to-end encrypted. The Windows installer remains unsigned.
