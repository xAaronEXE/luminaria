# Luminaria 0.2.33

Use a dedicated persistent external Edge profile for sign-in. Identify only a newly created window belonging to that profile, position it over Luminaria and request foreground activation. Do not move existing or unrelated browser windows. Default-browser fallback remains available when the desktop browser cannot launch. Windows foreground policy can restrict activation.

The dedicated browser profile may require a one-time provider login. Its browser storage stays in the active local profile's sign-in-browser directory; it does not change provider connections or the Luminaria identity session.

Validation: 39 browser-placement, identity, gate and sign-in poll-guard tests passed. Tests cover negative monitor coordinates, ownership matching, and exclusion of existing/unrelated windows. User confirmed real GitHub sign-in succeeds on 0.2.32; placement acceptance of this build remains pending.
