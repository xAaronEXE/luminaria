# Luminaria 0.2.10 — task overview redesign

- Redesigns the Task overview: recorded steps sit on a torus lattice grouped by
  region, connected by arcs with travelling activity, and labelled with their name
  and status (model-provided plans are tagged as such). A toolbar provides Follow
  activity, Focus, Outline and Return to chat; selecting a step opens a docked panel
  with Overview and Evidence tabs. Colors follow the black-and-white appearance
  tokens and any custom colors.
- Published as a new version so installations already on 0.2.9 are offered the
  update. Includes everything in 0.2.9 (update handoff and light-mode lattice).

Upgrading from 0.2.9 uses its automatic handoff. Upgrading from 0.2.8 or earlier
still requires closing Luminaria completely before proceeding in Setup.

Automated tests and a browser preview with mocked APIs passed. Real inference,
packaged desktop rendering and the upgrade itself still require acceptance. This
testing release is unsigned and does not certify those checks.
