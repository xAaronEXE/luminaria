# Luminaria 0.2.48

**Works on any Windows 10 or 11 PC, with nothing else to install.**
- Luminaria now includes its own Python and Node.js. The assistant can run code and create Word, Excel, PowerPoint and PDF files and charts straight away.
- The browser and Windows desktop connectors are included and ready to switch on.
- If the PC doesn't have Microsoft Edge WebView2, which draws the app window, the installer adds it automatically.
- The model runtime now includes the Microsoft C++ files it needs, so local models start on a fresh PC.

**Thousands of skills and connectors at the assistant's disposal.**
- A catalog of thousands of free skills (ready-made workflows) and connectors (tools for other apps and services) is now built in, and you can search it even offline.
- When a task needs something it doesn't have, the assistant finds the right skill or connector and adds it after you approve. In Full access it goes ahead on its own.
- Settings › Marketplace searches the same catalog. Skills install with all their files, at a fixed version, and show their license and source.
- Connectors from the catalog run with Luminaria's built-in Node.js and Python, so they work without installing anything else.

**More reliable tool use.** Some local models write out a tool request as text instead of carrying it out. Luminaria now spots this and runs the tool, and the assistant starts from its working folder when you ask about its files.

**Simpler Settings.** The model connection is handled automatically and no longer appears under Working folder.

The Windows installer is still unsigned, so Windows may show an unknown-publisher warning.
