# Luminaria 0.2.34

Desktop update consolidating the verified local builds since 0.2.17.

- Real Google, GitHub and Discord sign-in, account linking, server session checks, remembered devices, offline sign-out and first-use onboarding with a use-another-account option.
- Profile activity and Insights use recorded local measurements, with optional aggregate sync.
- Centered vector branding, animated sign-in artwork and a dedicated external sign-in browser positioned over Luminaria.
- Reorganized settings, red Log out button, guided integration/skill setup, searchable Memory and clearer tool/skill presentation.
- Workflow reliability, context-retention checks, per-model settings and opt-in hardware tuning from the earlier local builds.
- Profile loads identity, local profile metadata and the measured activity calendar from one fresh server response instead of two sequential requests. Authentication is not cached or bypassed.
- Preserve settings navigation scroll position and search when changing pages.
- Show loading and recoverable error states with Try again.
- Fetch independent settings/preferences in parallel and ignore responses for closed pages.
- Coalesce library decoration to one animation frame per mutation burst.
- Improve keyboard focus, numeric alignment, scrollbar stability and long-text wrapping.
