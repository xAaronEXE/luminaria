# Luminaria 0.2.14 — model choice and planning

- Model button: the model button in the message box opens a small menu instead
  of Settings. Choose Auto or any installed model, grouped into Standard and
  Abliterated. Picking a model turns Auto off; picking Auto turns it back on.
  While Auto is on, the button shows the model it last chose.
- Auto model pool: Settings → Orchestration lets Auto choose from all installed
  models, Standard only, Abliterated only, or models you tick individually.
- Smarter routing: the router model now only describes the task (what it needs
  and how demanding it is). Luminaria then ranks your allowed models using their
  listed strengths, size, whether the file fits in GPU memory, and the speed tests
  and quality checks you have run on this PC. Obvious requests skip the router
  entirely, saving a model swap. The activity view shows the ranking and reasons.
- Plan only: drafts the plan straight away from your description, with a goal
  and a short description of each step, only reads files when it needs facts,
  and must present the plan after a few investigation rounds. The plan is saved
  with the chat: open it with View plan or /plan, or ask for it in conversation.
  Carry out, revise, copy or clear it from the plan panel.

Tested with unit tests and in a browser against the real backend with
placeholder models. Routing quality with real loaded models, the GPU memory
check on Windows and the packaged desktop app still require acceptance. This
testing release is unsigned.
