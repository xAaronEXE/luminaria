# Luminaria 0.2.38

Fixes first-use local model setup on PCs without developer runtime paths. The installer now includes the llama.cpp Vulkan/CPU runtime and supporting libraries. **Use this model** configures the installed GGUF, discovers the bundled executable, selects the local endpoint, and refreshes the model-manager API key. The first question can start a configured manager even when no manager was launched at initial startup. Custom endpoints are not automatically restarted.

Voice setup uses pinned public download URLs, exact byte counts and SHA-256 checksums, atomic replacement, reuse of verified files and readable connection/publisher/disk-space errors. This removes the Hub SDK download dependency from voice setup. Downloaded voices include their model cards. The original reporter's exact 500 traceback was not available; packaged downloads were tested successfully.

Adds four model families with pinned publisher revisions and verified file metadata:
- Qwen3 0.6B and 1.7B: small Q8 starter models.
- Qwen3 32B: Q4_K_M and Q6_K.
- Qwen2.5 Coder 32B: Q4_K_M and Q6_K.

The larger models need substantial memory; published file/context estimates are not a fit guarantee. Models are downloaded only when selected for download. No model weights are included in the installer.


Cloud sync and sign-in behavior remain unchanged. The Windows installer remains unsigned.
