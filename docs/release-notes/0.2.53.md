# Luminaria 0.2.53

**Sort the Model library.** A new menu sorts the list by best fit for your PC, name, size (smallest or largest first), number of parameters, or recently added. Your choice is remembered.

**Honest fit ratings.**
- "May be unstable" now only appears when a model really is tight for your PC's memory. Before, some small models showed it just because they were built for short conversations.
- Models with a short built-in memory now say so plainly: a "Short memory" flag in the list, and a note explaining that it's a limit of the model itself, not your PC.
- Ratings are based on your graphics card's full memory, so they no longer change depending on what else happened to be open when Luminaria checked.

The Windows installer is still unsigned, so Windows may show an unknown-publisher warning.
