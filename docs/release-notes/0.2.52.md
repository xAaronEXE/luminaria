# Luminaria 0.2.52

**Many more models.** The Model library grows from 34 to about 280 models, with 87 that can see images. It now includes chat-ready local models from official publishers (such as Qwen, Google, Mistral, Microsoft, IBM and NVIDIA) and well-known GGUF publishers. Like every model in the library, each download is pinned to an exact version and checked against its published checksum. Models added this way are described briefly; open the model card for details.

**Manage models in bulk.** The Model library has two new buttons:
- **Download all that fit** queues the best size of every model that runs on your PC. It tells you how many models and how much space first, and skips any that won't fit.
- **Remove all models** deletes every downloaded model in one step. Your chats, memory and settings stay, and models you added from another folder stay on disk.

**Remove the model in use.** You can now uninstall the model Luminaria is currently using, including your last one. Luminaria stops it first and switches to another downloaded model if you have one.

**A pointer for new users.** If no model is installed yet, a small notice in the corner offers to open the Model library. Dismiss it any time; it goes away by itself once a model is installed.

**Clearer message without a model.** Sending a message with no model installed now explains how to get one.

The Windows installer is still unsigned, so Windows may show an unknown-publisher warning.
