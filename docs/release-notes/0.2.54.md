# Luminaria 0.2.54

**Dropdowns that match the app.** Every dropdown menu, including sort, access mode, microphone, Auto mode and tuning, now opens in Luminaria's own style in light and dark themes, instead of a plain white Windows list that was hard to read. They work with the keyboard too: arrow keys, Enter, Escape, and typing a letter to jump.

The Windows installer is still unsigned, so Windows may show an unknown-publisher warning.
