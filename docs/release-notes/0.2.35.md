# Luminaria 0.2.35

Adds opt-in account cloud sync for chats, selected files, memory, portable settings and workspace profile. AI inference continues running on your desktop. Model weights, credentials and device permissions stay local.

Sync includes revision checks, explicit conflict recovery, private storage and SHA-256 integrity checks. Conservative storage and request limits pause sync when exhausted. The per-file/compressed-chat limit is 20 MiB. These service limits are not an account-wide billing ceiling.

This is the installer already installed locally and verified against its build executable. First live upload and repeat sync passed. Production testing on a second PC, offline conflicts between physical PCs, and final native visual acceptance remain pending. Phone access is not implemented. Cloud sync is not end-to-end encrypted; hosted deletion currently requires support.

Release verification: 83 Python tests passed in isolated suites, four service suites passed, cloud-sync UI regression passed, and the real local Worker/D1/R2 two-client HTTP integration passed. No new production sync data was uploaded during these checks. The Windows installer remains unsigned.
