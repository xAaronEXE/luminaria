# 0.2.19 — hardware and tuning candidate

Local source candidate; not built, desktop verified, published, or release-ready.

Hardware & tuning is available in Settings. Inventory uses system/driver reports and
labels missing values. Opt-in benchmarks use installed weights and isolated temporary
loopback runtimes with thread/offload choices, three repetitions, first-token latency,
reported prompt/decode rates, RAM samples, GPU-memory snapshots and backend scheduling
delay. Browser scheduling/render observations remain separate.

Profiles retain model-file metadata, runtime executable hash/version, context and hardware
identity. Applying/rolling back a selection is explicit and requires restart; no running
configuration changes automatically. Changed provenance prevents stale profile application.
No weights downloaded, BIOS changes, experimental runtime forks or X3D optimization claims.

Verification: six isolated tests cover selection/rollback, provenance invalidation,
cancellation persistence, immediate/repeated Stop and invalid inputs; Python/JavaScript syntax checks passed.
No real inference tuning benchmark has been run. Desktop, resource-pressure, runtime
startup/cleanup and actual performance comparisons remain acceptance work.
