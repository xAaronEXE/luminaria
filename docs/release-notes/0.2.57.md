# Luminaria 0.2.57

**No more runaway replies.** If a model starts repeating itself, Luminaria now stops it, keeps one copy and tells you. It also uses llama.cpp's standard anti-repetition setting, so loops happen far less often.

**Planning is a conversation.** With Plan only on, Luminaria now answers what you actually said. When you brainstorm or correct it, it replies with short notes and asks questions, instead of printing the same plan again. The plan lives in its own card and is only written out when you ask to see it. It also looks things up before planning around facts it doesn't have.

**Long chats keep working.** Very long old replies are shortened in Luminaria's working memory (the full text is still saved). If summarizing a long chat fails, Luminaria carries on from the most recent messages instead of stopping the task.

**Installing packages works.** `pip install` now installs into the same Python that Luminaria runs your code with, so freshly installed packages are found. Commands that run too long say so plainly, and installs can take up to 10 minutes. When code fails because a module is missing, Luminaria gets the exact install command, including for names that differ, such as `cv2` → `opencv-python` and `docx` → `python-docx`.

The Windows installer is still unsigned, so Windows may show an unknown-publisher warning.
