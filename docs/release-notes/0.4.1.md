# Luminaria 0.4.1

- The updater uses the current installation folder, including custom locations. It requires a recovery copy before it opens Setup and restores the previous program files and installer registration if Setup fails or the new backend fails to start.
- Set a per-device download budget in the Model library. The default is 100 GiB. The budget applies to queued and resumed downloads, and the free-space safeguard still applies.
- Saved plans from the earlier command-check format carry their checks forward. Previously completed steps keep their status and show that their old verification evidence needs review.
- Windows Permissions includes a command sandbox self-check. Direct work can record and verify a completion check. The saved-plan reviewer can request a bounded repair and recheck.
