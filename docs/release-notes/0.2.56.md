# Luminaria 0.2.56

**Idle really means idle.** When Luminaria finishes a reply or a task, it stops completely until you ask for something else or a scheduled automation runs.
- **The model unloads from your graphics card** shortly after the work is done, instead of staying loaded for 30 minutes. If you'd rather your next message start faster, you can keep it loaded for 5 or 30 minutes in Settings › Hardware & tuning.
- **Clear model status** in the bottom corner: *Model off*, *Model loaded · unloads in 0:15*, or *Model working*.
- **The background and orb stop moving when nothing is happening.** They only animate while Luminaria is working, so it no longer looks busy, or uses your graphics card, while idle.
- **"Working" only shows while a task is really running.** It no longer gets stuck on after a task ends.

**`/skill` loads the skill.** Typing `/skill name` now loads that skill before Luminaria answers, so it follows the skill's steps instead of describing them.

**Does the work instead of handing it to you.** If Luminaria puts a whole program in its reply, or tells you to open a terminal and run or install things, it now saves the file, installs what's needed, runs it and fixes errors itself, then tells you what happened.

**Knows your models.** Luminaria now knows exactly which models you've installed and never makes up model names. Programs it writes can use your installed models through Luminaria's own local connection, so you don't need to download them a second time.

**Model fixes.**
- Models you download while Luminaria is open work right away, without restarting the app.
- Fixed "No model is installed yet" appearing when you'd removed all your models and then downloaded new ones.
- Models under 7B are marked "Chat only: too small for tasks" in the model picker. Use a 14B model or Auto for real work.

The Windows installer is still unsigned, so Windows may show an unknown-publisher warning.
