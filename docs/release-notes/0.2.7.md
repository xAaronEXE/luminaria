- The model library has 30 models: 15 Standard and 15 Abliterated, including Qwen3 14B and 30B-A3B, Qwen3 Coder 30B-A3B, gpt-oss 20B, Gemma 3 4B and 12B, Llama 3.1 8B, Mistral Nemo 12B, Phi-4 and DeepSeek R1 Distill Qwen 14B.
- Every download is pinned to a specific publisher revision, and its size and SHA256 are checked before the model is registered.
- Gemma 3 models can add a vision projector so you can attach images. One projector file is shared by a model and its abliterated version.
- Each model shows its configured context next to the context supported by the file, and an estimated memory use made from the file size and the context cache. Estimates are not fit guarantees.
- Models has a clearer storage bar showing other files, model files, the selected download and the space left afterward. Download is turned off, with the reason, when it would leave less than 1 GB free or pass the 100 GB budget.
- The library list is compact, can be filtered by Coding, Reasoning, Writing, Tools and Vision, and keeps the selected model's details in view while you scroll.
