# Luminaria 0.2.49

**Tidier updates.**
- Installing or updating now replaces the program files as a whole, so files left over from older versions are removed. Your chats, settings, models and files are never touched.
- After an update, Luminaria deletes the installer it downloaded and any unfinished downloads. A newer update that hasn't been installed yet is kept.

The Windows installer is still unsigned, so Windows may show an unknown-publisher warning.
