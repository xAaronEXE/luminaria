# Luminaria 0.2.8 — candidate, do not publish yet

Packaged Windows acceptance is pending. Do not publish this version until Aaron accepts it.

## Spatial work
- A persistent particle entity navigates an execution lattice built from recorded work.
- Overview, current-activity follow, focus, node labels, evidence inspection, Activity
  links, keyboard controls and an accessible outline/fallback.
- Model-provided plans and reasoning are labelled separately from executed tools.
- Task history survives reconnects; earlier runs collapse into inspectable clusters.
- Real audio-frame inputs drive the entity; native microphone/TTS acceptance remains pending.
- Typed messages can queue while a task runs, with cancellation/retry and voice priority.

## Appearance
- Black/white Light, Dark and Follow system, with persistent shared/per-mode accents.
- Existing global colour controls cover interface and spatial materials.
- Startup cache remains PC-wide and can briefly show a prior profile's appearance.

## Verification boundary
Isolated automated tests and browser previews with mocked APIs do not certify real
model quality, native audio, graphics performance, signing or Windows acceptance.
See docs/testing-0.2.8.md and docs/verification-0.2.8.md.
