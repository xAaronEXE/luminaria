# Luminaria 0.2.51

**Documents just work.** Ask for a Word, Excel, PowerPoint or PDF file and the assistant makes a real one with the built-in tools and saves it in your working folder. It no longer sends you to review a plan instead.

**Skills finish properly.** Creative skills, like making a timeline or a slide deck, can now be marked complete once their files exist. The assistant also says plainly when a step failed instead of reporting success.

**Tidier working folder.** The scripts the assistant runs behind the scenes are now kept inside Luminaria's own folder, not in your working folder. Downloads for connectors you add from the Marketplace are kept there too.

**Clearer steps.** A reply with a single step opens straight to its details instead of repeating the same line.

**Fix.** The assistant now knows it can read skill files, including a skill's scripts.

The Windows installer is still unsigned, so Windows may show an unknown-publisher warning.
