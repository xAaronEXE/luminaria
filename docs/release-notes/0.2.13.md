# Luminaria 0.2.13 — annotation update

Published as 0.2.13 so installations of the locally built 0.2.12 are offered it.

- Appearance: accent and color changes save immediately and in order, and stay
  after closing Luminaria or changing local profile.
- Account and settings open from the sidebar footer. Chat menus are compact,
  anchored and keyboard accessible.
- Sign-in: Google, GitHub and Discord sessions can coexist. Signing in with a
  second provider while signed in links it to the same Luminaria account on the
  sign-in service; nothing is merged by matching email. Linking a provider that
  already belongs to a different identity is refused with no change.
- Working folder: choose it from the composer menu or with a folder browser in
  Settings, with a plain explanation of what file tools can reach.
- Context: plain-language settings for when compaction starts, how many recent
  turns stay verbatim and the answer budget, plus per-model context limits.
  Summaries use fixed sections, keep message references, never copy credentials,
  and are retried once if truncated or over budget; otherwise the original
  history and previous summary are kept unchanged.
- Optional model routing: a small installed model picks one installed
  specialist for each new task turn and falls back to your selected model if its
  choice is invalid. Approvals and Plan only restrictions still apply.
- Task overview: drag to orbit, Shift or right-drag to pan, wheel to zoom
  (Alt+arrows, Shift+arrows and +/- on the keyboard). Regions have their own
  colors; the toolbar keeps Follow activity and Return to chat. The outline
  still opens automatically when 3D is unavailable.
- Skills, tools and integrations show clearer purposes, grouping and setup
  guidance. A completed run's model and measured speed stay readable after a
  restart.

The sign-in service needs its database updated before this release is used for
linking (two new tables). One real routing handoff (Qwen 4B to Qwen Coder 30B) and
one real compaction were tested in a source build. Packaged desktop behaviour,
real multi-provider linking, routing quality, VRAM use and the upgrade itself
still require acceptance. This testing release is unsigned.
