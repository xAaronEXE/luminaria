# Luminaria 0.4.5 candidate

- Model-led Agent lets the selected model choose how to investigate, plan and act. Verification is shown separately from its reply.
- Direct Chat provides tool-free conversation. Classic Agent remains the default pending live comparison.
- Agent runs can continue past the former round limit while bounded by time, generation and model-step limits. Identical read results can trigger a checkpoint.
- DeepSeek's official thinking API retains provider-scoped reasoning for tool round trips. Local runtimes and other services keep their existing wire behavior.
