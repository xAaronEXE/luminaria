# Luminaria 0.2.11 — color, status, Plan only and sign-in

- The workspace scene follows your accent color: lattice, pathways, glow,
  particles and the assistant entity are tinted from it unless you set those
  colors individually. Without an accent the default stays black and white.
- The entity shows its state. Its color changes for listening, thinking,
  working, waiting for approval, interruptions and errors, and a small status
  pill beneath it names the state ("Ready", "Working · Read file", "Waiting for
  approval"). On the home screen it rests beside the welcome text.
- Plan only: a composer toggle that lets the assistant investigate with
  read-only tools (files, search, memory, skills) and record a plan without
  changing anything. Afterwards choose Carry out plan or Revise plan. Tools
  that edit, run code, fetch pages or need approval are not offered, and the
  app refuses them if requested.
- Models: removing a downloaded model or vision projector is now labelled
  Uninstall.
- Sign-in: Google and Discord are ready on the service side once their
  publisher applications are registered. Cancelling or denying consent in the
  browser now stops the desktop waiting immediately, and the browser shows a
  clear result page.

Automated tests and a browser preview with mocked APIs passed. Real inference,
real Google and Discord sign-in, packaged desktop rendering and the upgrade
itself still require acceptance. This testing release is unsigned.
