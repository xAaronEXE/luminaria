# Luminaria 0.4.0

## Plans that finish
- A plan pauses if an interrupted action may have changed something. Check what happened, then record the outcome in Activity before continuing.
- Greetings stay in chat, research requests use web tools, and certain higher-impact requests open a plan for review. A plan can list files and folders to leave untouched.
- Luminaria reruns completed offline command checks on Windows before reporting that the plan passed.
- Steps that depend on earlier work wait for it to pass. Before the final report, Luminaria checks again that required files still exist and contain what the plan expects.
- Required checks must run before work continues. If the assistant makes more changes after running a check, it runs the check again before claiming success.
- **Every way of starting a plan now runs it step by step.** The Carry out plan button in the status bar and typing "go ahead" or "do it" used to run the whole plan in one go, which ran out of room partway. They now use the same step-by-step runner as the Plan panel.
- **Luminaria decides when a step is finished, not the model.** Each step can have a check: a command that must succeed, or a file that must exist or contain something. A step counts as checked only when its check passes.
- **Checks are graded.** A step checked with a test Luminaria wrote during the same plan shows *Done · checked by its own test*, because that proves less than a test you already had.
- **Honest results.** Steps show *Done · checked*, *Done · not proven* or the reason they stopped. The plan report says exactly how many steps were proven, and never calls unproven work finished.
- **Big steps keep going.** A step that needs more work continues automatically, up to three tries, as long as it's making progress. Repeating the same failing approach stops it instead of looping.
- **Continue plan** picks up at the step that stopped. Steps that already finished are not run again.
- **Safer after a crash or restart.** A plan interrupted between or during steps can be resumed, and actions that already succeeded are not repeated.
- **The model can't skip steps.** While a plan runs, the model can add steps but can't mark steps done, rename them or drop them.

## It can look at what it built
- **Screenshot check.** When Luminaria builds a web page or app screen, it can take a screenshot of it (a file on your PC or a page on localhost) and, if your model can see images, look for problems such as overlapping text, missing styles or a broken layout, then fix them. It uses the Microsoft Edge that comes with Windows, without your profile or sign-ins.

## Sources it really read
- When Luminaria researches something, every link in its answer must come from a page or search result it actually read during the task. A link it made up or remembered is caught, and it's asked to remove it or check it first.

## Code stays out of the chat
- When Luminaria writes code and runs or saves it, the code no longer fills the chat. You see what it did, with the code one click away under **Code it used**. Ask to see the code and it's shown as before.

## Files and folders
- **Attach any file**, of any type and size, from anywhere on your PC. Big files and other types (Excel, zip, video) are attached where they are, without copying.
- **Attach any folder.** It stays where it is; Luminaria works on it in place.
- **Drag and drop** files or folders onto the window to attach them.
- **Windows file and folder dialogs** now open in front of Luminaria.
- Up to 10 attachments per message.

## Steer and review a task
- **Send now.** A message you type while Luminaria is working used to wait until the task ended. **Send now** on the queued message hands it over right away; Luminaria reads it before its next step, without stopping.
- **Export run record.** Activity has a new button that saves everything about a chat's recent work in one file: steps, actions, checks and messages. It makes it possible to see exactly what happened when a task goes wrong.

## Undo and safer file changes
- **Undo file changes.** After a task, one button puts back the files it changed, removes the files it created and brings back the ones it deleted. You see the full list before anything happens.
- **Honest about limits.** A file is only put back if it's still exactly as the task left it; if you or another program changed it since, it's left alone and listed. Anything a command or script did (installed programs, online actions) can't be undone, and the list says so.
- **Files are saved whole or not at all.** A crash or power cut in the middle of a save no longer leaves a half-written file.

## Where Luminaria can work
- **Program Files and ProgramData are now open** to Luminaria. Changing anything there always asks you first, even in Full access.
- **Strictly off limits, in every mode:** the Windows folder, saved credentials, Luminaria's own data, other people's profiles on this PC, the Recycle Bin and Windows' recovery folders. Commands and scripts that name these places are refused too.
- **Drives.** Luminaria can see and work on every drive. **Settings › Permissions › Drives** lets you untick any drive you want it kept away from.
- **Nothing left running behind your back.** On Windows, stopping a command or hitting its time limit also ends the programs it started.
- **Its own sandbox.** On Windows, commands and code run in a temporary, offline AppContainer in both approval modes. They can read copies of the input files selected for that run. Browser, desktop and file tools have their own permissions.
- **No administrator commands, but an admin helper.** Luminaria never runs administrator commands. For a short list of jobs that need it (installing or uninstalling a program with winget, turning on a Windows feature, starting, stopping or configuring a service, opening a port on private networks), a small helper does exactly that job and nothing else. It always asks you first and Windows shows its own prompt. In **Settings › Permissions** you can let Hands-free do chosen jobs without asking. Services that keep Windows running or secure are never touched.

## Model library
- The selected model's panel stays in view while you scroll the list.
- **Best fit** now picks the fastest size when every size of a model runs slowly on your PC.
- Hover a model to see its full name.
- **Cleaner catalog.** About 20 models that showed up with scrambled names (long strings of letters and numbers) now have their real names.

## Models
- **Settings fit the task.** Code, tool use and plan steps run with steadier settings for more consistent results; writing gets a little more freedom; conversation is unchanged.
- **Auto picks more reliably.** The small model that decides which model handles a request can no longer answer in a broken format.

## Safer updates
- **An update that can't start is undone automatically.** Before installing, Luminaria keeps a copy of the current version (not your chats, models or files, which are never touched). If the new version doesn't start within about two and a half minutes, the previous version is put back and Luminaria tells you what happened.

## Sync that only you can read
- **Sync is off until you set it up.** Nothing leaves your PC unless you choose a place to sync.
- **End-to-end encrypted.** Chats, files, memory and settings are encrypted on your PC with a sync key only your devices have. Wherever they're stored sees only scrambled files: not your chats, file names or contents.
- **Sync through a folder you already sync.** Pick your OneDrive, Google Drive or Dropbox folder, or a shared folder on your network, and your sync app carries the encrypted data to your other PCs. No new account, no server.
- **Join from another PC with your sync key**, shown once when you set up sync and any time under **Show sync key**. It's also your recovery key; nobody can reset it.
- If you used cloud sync before, set it up again in **Settings › Cloud sync**. Your data on each PC is untouched.

## Voice
- Pick a local model for quick spoken replies in Model roles. Spoken work requests use the usual plan and tool approvals.

## Private cloud sync
- Connect an encrypted sync Worker in your own Cloudflare account using a device key. Your separate sync key stays on your devices.

## Offline Windows commands
- PowerShell, Python and JavaScript tools run with Windows-enforced access limits and no network capability. Add workspace files as inputs to make temporary copies available to a command. Use the file tools to save lasting changes.
- Commands can use bundled Python offline. Internet downloads and development servers are unavailable inside the command workspace.

## Model results and voices
- The Model library shows exact matches from Epoch AI's published benchmark data alongside the scores measured on your own PC.
- Choose Heart (Kokoro) for offline speech. Piper remains available.
- Qwen3 uses its own thinking switch and sampling options. Llama, Gemma, and DeepSeek use their model's built-in chat template.
