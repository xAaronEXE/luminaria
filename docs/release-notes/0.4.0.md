# Luminaria 0.4.0

## Plans that finish
- **Every way of starting a plan now runs it step by step.** The Carry out plan button in the status bar and typing "go ahead" or "do it" used to run the whole plan in one go, which ran out of room partway. They now use the same step-by-step runner as the Plan panel.
- **Luminaria decides when a step is finished, not the model.** Each step can have a check: a command that must succeed, or a file that must exist or contain something. A step counts as checked only when its check passes.
- **Honest results.** Steps show *Done · checked*, *Done · not proven* or the reason they stopped. The plan report says exactly how many steps were proven, and never calls unproven work finished.
- **Big steps keep going.** A step that needs more work continues automatically, up to three tries, as long as it's making progress. Repeating the same failing approach stops it instead of looping.
- **Continue plan** picks up at the step that stopped. Steps that already finished are not run again.
- **Safer after a crash or restart.** A plan interrupted between or during steps can be resumed, and actions that already succeeded are not repeated.
- **The model can't skip steps.** While a plan runs, the model can add steps but can't mark steps done, rename them or drop them.

## Code stays out of the chat
- When Luminaria writes code and runs or saves it, the code no longer fills the chat. You see what it did, with the code one click away under **Code it used**. Ask to see the code and it's shown as before.

## Files and folders
- **Attach any file**, of any type and size, from anywhere on your PC. Big files and other types (Excel, zip, video) are attached where they are, without copying.
- **Attach any folder.** It stays where it is; Luminaria works on it in place.
- **Drag and drop** files or folders onto the window to attach them.
- **Windows file and folder dialogs** now open in front of Luminaria.
- Up to 10 attachments per message.

## Steer and review a task
- **Send now.** A message you type while Luminaria is working used to wait until the task ended. **Send now** on the queued message hands it over right away; Luminaria reads it before its next step, without stopping.
- **Export run record.** Activity has a new button that saves everything about a chat's recent work in one file: steps, actions, checks and messages. It makes it possible to see exactly what happened when a task goes wrong.

## Undo and safer file changes
- **Undo file changes.** After a task, one button puts back the files it changed, removes the files it created and brings back the ones it deleted. You see the full list before anything happens.
- **Honest about limits.** A file is only put back if it's still exactly as the task left it; if you or another program changed it since, it's left alone and listed. Anything a command or script did (installed programs, online actions) can't be undone, and the list says so.
- **Files are saved whole or not at all.** A crash or power cut in the middle of a save no longer leaves a half-written file.

## Where Luminaria can work
- **Program Files and ProgramData are now open** to Luminaria. Changing anything there always asks you first, even in Full access.
- **Strictly off limits, in every mode:** the Windows folder, saved credentials, Luminaria's own data, other people's profiles on this PC, the Recycle Bin and Windows' recovery folders. Commands and scripts that name these places are refused too.
- **No administrator commands.** Luminaria doesn't run commands as administrator; it tells you which step needs it so you can do that part.

## Model library
- The selected model's panel stays in view while you scroll the list.
- **Best fit** now picks the fastest size when every size of a model runs slowly on your PC.
- Hover a model to see its full name.
