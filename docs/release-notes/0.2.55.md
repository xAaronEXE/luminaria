# Luminaria 0.2.55

**Memory you can read and edit.** Memory is now one plain Markdown page, like a notes file. Open Memory to see everything Luminaria knows about you under About me, Preferences and Notes. Edit, reorder or delete anything, switch to Preview to see it formatted, and press Save (or Ctrl+S). When you ask Luminaria to remember something, it adds a dated line under Notes. Your existing memories are moved over automatically the first time you open the new version.

**Project notes.** Each working folder can have its own notes. Open Memory › This project › Start project notes to write down what Luminaria should know about that project. It reads them at the start of every task in that folder.

**Checks its own work.** After creating a document, spreadsheet, slide deck, PDF, web page or image, Luminaria now opens the file to make sure it is real and complete before saying it is done. For example, it catches plain text that was saved with a .docx name.

**Faster, more focused answers.** Luminaria starts each task with the everyday tools and loads the rest only when it needs them, so it chooses the right tool more often. Its instructions are also arranged so your model can reuse its earlier work between messages, which makes replies start sooner in long chats.

The Windows installer is still unsigned, so Windows may show an unknown-publisher warning.
