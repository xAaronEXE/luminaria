# Luminaria 0.2.55

**Your whole PC, always.** Luminaria is no longer limited to one folder. Name any folder, drive or file in your message, such as "tidy up D:\\Photos" or "summarize the report on my Desktop", and it works there. The old working folder is now the default folder: where new files go when you don't say where. The Whole PC switch is gone because it's always on. Windows system folders, Program Files, credential folders and Luminaria's private data stay off limits, and Ask me first still asks before changes.

**Extensions: skills, connectors and workflows in one place.** Library › Extensions replaces the separate Skills, Integrations, Marketplace and Automations pages. Every item looks and works the same way: what it is, whether it's ready, one main button, and setup laid out as numbered steps. Tabs show what you have installed, let you browse thousands of free skills and connectors, and group skills, connectors and workflows on their own. If a skill needs something, its setup steps take you straight to the fix, such as connecting GitHub or turning on computer tools.

**Memory you can read and edit.** Memory is now one plain Markdown page, like a notes file. Your memory belongs to your profile: it applies in every chat and every folder, and syncs with your account. Open Memory to see everything Luminaria knows about you under About me, Preferences and Notes. Edit, reorder or delete anything, switch to Preview to see it formatted, and press Save (or Ctrl+S). When you ask Luminaria to remember something, it adds a dated line under Notes. Your existing memories are moved over automatically the first time you open the new version.

**Project notes.** Any folder can have its own notes in a LUMINARIA.md file. Open Memory › This project › Start project notes to write them for your default folder. Luminaria reads them in every task, and reads another folder's notes when you work there.

**Checks its own work.** After creating a document, spreadsheet, slide deck, PDF, web page or image, Luminaria now opens the file to make sure it is real and complete before saying it is done. For example, it catches plain text that was saved with a .docx name.

**Faster, more focused answers.** Luminaria starts each task with the everyday tools and loads the rest only when it needs them, so it chooses the right tool more often. Its instructions are also arranged so your model can reuse its earlier work between messages, which makes replies start sooner in long chats.

The Windows installer is still unsigned, so Windows may show an unknown-publisher warning.
