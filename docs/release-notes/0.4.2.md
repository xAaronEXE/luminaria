# Luminaria 0.4.2

- Clear file and code work requests need tool evidence before the app marks them complete. An unsupported completion claim gets one follow-up and remains unverified if the work still has no evidence.
- If the assistant announces a file search and ends the turn before running it, Luminaria checks the action journal and gives the assistant a chance to carry out the search.
- A saved plan with a completed step that lacks a passing check is reported as unverified in the run status.
- When a specialist model fails to warm up, Luminaria continues through its normal model recovery path.
