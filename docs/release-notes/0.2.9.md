# Luminaria 0.2.9 — update handoff fix

- Install verifies the download, requests a normal app shutdown and waits before
  opening Setup. A separate helper can stop the captured app and its owned model
  manager if they remain running, preventing locked executable replacement errors.
- Active agent tasks must finish or stop before installation can begin.
- Setup checks for a running Luminaria instance before replacing program files.
- Handoff and Setup logs are saved beside the downloaded installer.
- Includes the remaining-scope document and a planning-test cleanup fix.

When upgrading from 0.2.8, its old handoff is still in use. Close Luminaria completely
before proceeding in Setup; the automatic handoff is available in 0.2.9 onward.
Do not skip locked files. Profiles, models and user files remain in place.

Automated tests and a Windows disposable-process handoff test passed. Real packaged
automatic shutdown, forced fallback and data-preserving upgrade still require
acceptance. This testing release is unsigned and does not certify those checks.
