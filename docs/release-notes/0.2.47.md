# Luminaria 0.2.47

**Full access in one click.** Settings › Permissions has a new **Grant full access** button. It turns on Hands-free, every tool, and a new **Whole PC** option that lets the assistant work in any folder on any drive. Switching modes now applies to your next message, with no restart. Luminaria's own settings, program files, Windows and credential folders stay off limits.

**Hands-free follows through.** When you ask for something to be done, the assistant now does it instead of only describing it, and it is less likely to repeat itself.

**Marketplace.** Settings › Marketplace lists free skills from public GitHub repositories and thousands of connectors from the official MCP Registry. Install with one click. You can add your own skill repositories. Connectors run third-party code, so each install asks you to confirm.

**Model library.**
- Fit colors now run from green (runs well) through yellow and orange to red (too large).
- Each quantization shows its saved benchmark: speed, a plain verdict, and how much context it handles comfortably on your PC.

**Everything opens in your default browser.** Signing in with Google, GitHub or Discord, and every outside link, now opens in the browser you normally use.

**Integrations** opens inside Settings like every other page.

**Safer and steadier.** Tighter limits on what web access and file tools can reach, a clearer warning before adding skills and connectors, steadier replies when the model server hiccups, and cloud sync now declines to upload an overly broad working folder.

The Windows installer is still unsigned, so Windows may show an unknown-publisher warning.
