# Luminaria 0.2.41

**A new sign-in screen.** Sign-in now matches the rest of the app:
- slow aurora light behind everything
- the Lumen orb at the center, circled by orbiting rings
- a frosted card with large buttons for Google, GitHub and Discord

The privacy note explains in one place what signing in does and doesn't do. On narrow windows, the orb sits above the card. Animation stops when Motion is off or your system asks for reduced motion.
