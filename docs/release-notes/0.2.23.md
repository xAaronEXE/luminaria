# 0.2.23 — Offline sign-out

Signing out now removes this PC's primary and provider credentials, pending sign-in flows and offline verification cache before contacting the identity server. Local logout succeeds even when the network is unavailable, the server returns an error, or a saved credential is corrupt. Server revocation is attempted once per distinct token, with a five-second request timeout. Unconfirmed remote revocation is explained explicitly; no bearer token is retained for later retry. Other signed-in devices are not signed out.

When sign-in is required, successful logout opens the sign-in gate directly. Chats, files, models and profile preferences remain in place.
